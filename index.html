The ten topics

Every topic follows the same shape: the big idea, the skills you need to be able to do unaided, the core knowledge in plain language, the formula bank, a fully worked example, and the errors that most often cost marks.

How the questions work

Generated, not recycled

Every question is built fresh from a template with new numbers and a new context, so you can practise the same skill twenty times without memorising an answer.

Steps that name the formula

Each step shows the substitution and links to the exact QCAA formula-book entry it comes from — the same sheet you are given in the exam.

The pitfall, spelled out

Every solution ends with the specific error that loses marks on that question type, drawn from the common-error lists for each topic.
